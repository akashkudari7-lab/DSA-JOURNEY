# Pointers: Core Concepts & Quick Reference

---

## 1. What is a Pointer?

A **pointer** is a variable that stores the **memory address** of another variable rather than storing a direct value.

```
Variable:  x = 10               Pointer:  ptr = 0x1004
Address:   0x1004               Address:  0x2000
Value:     [ 10 ]               Value:    [ 0x1004 ]
             ▲                                │
             └────────────────────────────────┘
                 (ptr points to x)
```

---

## 2. Key Operators

| Operator | Name | Purpose | Example |
| :--- | :--- | :--- | :--- |
| `&` | **Address-of** | Returns the memory address of a variable | `&x` $\rightarrow$ `0x1004` |
| `*` | **Dereference** | Accesses or modifies the value stored at the address | `*ptr` $\rightarrow$ `10` |

### Basic Syntax (C++)

```cpp
#include <iostream>

int main() {
    int x = 10;
    int *ptr = &x; // ptr stores address of x

    std::cout << "Value of x: " << x << "\n";       // 10
    std::cout << "Address of x: " << &x << "\n";     // e.g. 0x7ffd5
    std::cout << "Value of ptr: " << ptr << "\n";    // 0x7ffd5
    std::cout << "Value at *ptr: " << *ptr << "\n";  // 10

    // Modifying through pointer
    *ptr = 25;
    std::cout << "Updated x: " << x << "\n";        // 25
    return 0;
}
```

---

## 3. Pointer Arithmetic

Pointers move in memory by multiples of the data type size (`sizeof(type)` bytes):

- `ptr + 1` moves forward by `sizeof(*ptr)` bytes (e.g., 4 bytes for `int`).
- `ptr - 1` moves backward by `sizeof(*ptr)` bytes.
- `ptr2 - ptr1` returns the number of elements between two pointers of the same array.

```cpp
int arr[] = {10, 20, 30};
int *p = arr; // points to arr[0]

std::cout << *p;       // 10
std::cout << *(p + 1); // 20
std::cout << *(p + 2); // 30
```

## 4. Special Types of Pointers

1. **Null Pointer (`nullptr`)**: Points to nothing (address `0`). Used to avoid uninitialized pointer bugs.
   ```cpp
   int *ptr = nullptr;
   ```

2. **Wild Pointer**: An uninitialized pointer that points to an arbitrary, invalid memory location.
   ```cpp
   int *ptr; // Dangerous! Always initialize to nullptr or a valid address.
   ```

3. **Dangling Pointer**: A pointer pointing to memory that has already been deallocated or freed.
   ```cpp
   int *ptr = new int(5);
   delete ptr; // ptr is now dangling
   ptr = nullptr; // Safe practice: reset to nullptr
   ```

4. **Void Pointer (`void*`)**: A generic pointer that holds an address of any data type. Cannot be dereferenced directly without typecasting.
   ```cpp
   int a = 5;
   void *gp = &a;
   std::cout << *(static_cast<int*>(gp));
   ```

5. **Double Pointer (`**`)**: A pointer that stores the address of another pointer.
   ```cpp
   int x = 10;
   int *p = &x;
   int **pp = &p; // pp -> p -> x
   ```

---

## 5. Pointer vs Reference (C++)

| Feature | Pointer (`*`) | Reference (`&`) |
| :--- | :--- | :--- |
| **Reassignment** | Can point to different objects | Cannot be reseated once bound |
| **Null Value** | Can be `nullptr` | Cannot be null (must bind to valid object) |
| **Syntax** | Requires `*` and `&` operators | Behaves like an alias (clean syntax) |
| **Arithmetic** | Supported (`ptr++`, `ptr + k`) | Not supported |

---

## 6. Common Pitfalls to Avoid

- **Dereferencing `nullptr` or wild pointer:** Results in Segmentation Fault / Undefined Behavior.
- **Memory Leaks:** Allocating heap memory (`new` / `malloc`) without freeing it (`delete` / `free`).
- **Buffer Overflow:** Accessing memory beyond array boundaries via pointer arithmetic.
